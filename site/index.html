Lyrics on your desktop, not in a window.

A frameless, fully transparent, click-through overlay that paints word-synced lyrics straight onto your wallpaper — following whatever is playing on Spotify. No panel, no album art, no border. Clicks pass right through it.

What it does

Word-by-word fill

The active line fills a word at a time as it is sung. Where a source only provides line-level timing, word timings are synthesized by distributing the line across its words by character weight — close to indistinguishable, and it covers every track.

Never in the way

Click-through by default, kept out of Alt-Tab and the taskbar, and it never takes focus from what you are actually doing. One hotkey makes it a real window again when you want to move it.

Smooth, not steppy

Spotify is polled once a second, but the overlay runs its own clock at frame rate and eases the correction instead of snapping. Seeking resyncs within about a second; pausing freezes the wipe mid-word.

Controls

Ctrl Alt L
Interactive mode — drag, resize, open settings
Ctrl Alt H
Show or hide the overlay
Ctrl Alt [
Nudge the sync offset 100 ms earlier
Ctrl Alt ]
Nudge the sync offset 100 ms later
Ctrl Alt 0
Reset the offset

Run it from source

# Needs Node 24 and a Spotify client ID (free, no secret required)
git clone https://github.com/akshit-bansal11/lyric-veil
cd lyric-veil
npm install
cp .env.example .env   # paste your client ID in
npm run dev

Authentication is Authorization Code + PKCE against a loopback redirect, so no client secret is ever shipped. The only scopes requested are read-only playback state — Lyric Veil cannot control your music.
